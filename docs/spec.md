## 1. 개요 (Overview)

Ootique는 매일 바뀌는 '오늘의 컬러'에 맞춰 사용자가 자신의 OOTD(Outfit Of The Day)를 기록하고, 6자리 초대 코드로 친구와 1:1 사진을 자동 동기화/공유할 수 있는 iOS 중심 Expo React Native 앱입니다.

- **플랫폼**: iOS (iPhone Expo Go 호환 Expo SDK 54)
- **수익화**: 최근 7일 로컬 보관(무료) / `Ootique Plus` 4,900원 1회 구매 시 전체 로컬 기록 영구 보관
- **백엔드**: Supabase Edge Functions (표준 `fetch` 통신, SDK 미사용), 비공개 Storage, Postgres

## 2. 완성된 기능 명세 (Completed Specifications)

### 2.1 오늘의 컬러 & 룰렛 시스템
- **날짜 기반 고정 컬러**: 동일 날짜(YYYY-MM-DD)에는 모든 사용자에게 동일한 6자리 헥사코드와 컬러 명칭이 제공됩니다.
- **룰렛 인터랙션**: 앱 실행 시 당일 컬러 룰렛 애니메이션을 통해 '오늘의 컬러'를 공개합니다.

### 2.2 사진 촬영/선택 및 기기 저장
- **카메라 및 앨범 통합**: iOS 기본 카메라 촬영 및 사진 앨범 선택 지원.
- **기기 내부 보관**: 원본 사진은 서버에 상주하지 않으며(친구 공유 시에만 버킷 임시 전달), 기기 로컬 파일시스템에 저장됩니다.
- **안전영역(Safe Area)**: iOS 및 안드로이드 하단 시스템 영역과 탭바가 겹치지 않도록 `react-native-safe-area-context` 5.6 적용.

### 2.3 6자리 친구 코드 1:1 자동 동기화
- **초대 코드 생성 및 참가**:
  - 사용자 A가 6자리 초대 코드를 생성하면 클립보드에 자동 복사됩니다.
  - 사용자 B가 코드 입력칸에 붙여넣기(6/6자 확인) 후 참가 요청을 보냅니다.
  - 초대 코드는 10분 만료되며 방장(A) 승인 후 방이 2명으로 닫힙니다.
- **상대 사진 자동 표시**:
  - 수동 사진 선택 없이 5초 폴링을 통해 상대방이 사진을 올리면 자동으로 양쪽 화면에 표시됩니다.
  - 두 사람의 사진이 모두 모이면 A/B 공유 카드를 생성할 수 있습니다.
- **보안 및 토큰**:
  - `expo-secure-store`에 회원 토큰을 저장하며 서버에는 토큰 해시만 보관합니다.
  - 사진 교체/삭제 시 양쪽 기기에 동일 상태가 즉시 반영됩니다.

### 2.4 로컬 데이터 자동 정리 및 Ootique Plus (IAP)
- **무료 사용자**: 최근 7일(오늘 포함) 데이터만 보관하며, 8일째부터는 오래된 사진과 기록을 자동 정리합니다.
- **Plus 사용자 (`com.lodim.ootique.plus`)**: 4,900원 비소모성 1회 구매 상품. StoreKit 영수증 조회를 통해 8일째 자동 정리를 면제하고 전체 기록을 보관합니다.
- **복원 (Restore)**: 서버 계정 없이 Apple 계정 StoreKit 구매 내역으로 언제든 Plus 권한을 복원합니다.
