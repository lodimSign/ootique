개인정보 처리방침

시행일: 2026년 8월 3일

Ootique는 계정을 만들지 않으며 개인정보를 수집하거나 추적하지 않습니다.

  • 선택한 사진과 OOTD 기록은 사용자의 기기에만 저장됩니다.
  • 사진과 기록을 외부 서버로 전송하지 않습니다.
  • 광고, 분석 도구, AI API를 사용하지 않습니다.
  • 외부 공유는 사용자가 iOS 공유 시트를 직접 실행할 때만 이루어집니다.
  • 앱의 기록 화면에서 개별 기록 또는 모든 로컬 데이터를 삭제할 수 있습니다.
