하루 한 색으로 시작하는 작은 OOTD 챌린지입니다.

개인정보 처리방침

시행일: 2026년 8월 4일

Ootique는 계정을 만들지 않으며 이름, 이메일, 전화번호를 요구하지 않습니다. 광고와 분석 도구를 넣지 않았고 사용자를 추적하지 않습니다.

혼자 모드

  • 선택한 사진과 OOTD 기록은 사용자의 기기에만 저장됩니다.
  • 외부 서버로 전송하지 않습니다.

친구 모드

  • 연결된 두 사람이 서로의 사진을 볼 수 있도록 사진 한 장이 비공개 저장소로 전송됩니다.
  • 사진은 같은 6자리 코드로 연결해 승인된 상대만 볼 수 있습니다. 공개 주소를 만들지 않으며 검색되지 않습니다.
  • 기기마다 임의로 만든 토큰으로 인증하며, 서버에는 토큰 원문이 아니라 해시만 저장합니다. 이 토큰은 이름·이메일 등 어떤 신원 정보와도 연결되지 않습니다.
  • 초대 코드는 10분 뒤 만료되고, 방은 두 사람이 연결되면 닫힙니다.
  • 사용자는 자기 사진을 언제든 교체하거나 삭제할 수 있으며, 삭제하면 저장소에서도 지워집니다.
  • 과도한 요청을 막기 위해 접속 IP를 해시로 바꿔 60초 동안만 사용하고 원본 IP는 저장하지 않습니다.

공통

  • 광고, 분석 도구, AI API를 사용하지 않습니다.
  • 외부 공유는 사용자가 기기의 공유 시트를 직접 실행할 때만 이루어집니다.
  • 앱의 기록 화면에서 개별 기록 또는 모든 로컬 데이터를 삭제할 수 있습니다.
  • 수집한 정보를 제3자에게 판매하거나 광고 목적으로 제공하지 않습니다.
  • 만 14세 미만 아동을 대상으로 하지 않습니다.

사진 저장에는 Supabase를 사용합니다. 서버는 대한민국(서울) 지역에 있습니다.

부적절한 콘텐츠 무관용 원칙

시행일: 2026년 8월 7일 · 이 원칙은 Ootique 이용약관(EULA)의 일부입니다.

Ootique의 공개 투표에 올라오는 사진은 사용자 생성 콘텐츠입니다. Ootique는 부적절한 콘텐츠와 악성 사용자에 대해 무관용 원칙을 적용합니다.

금지되는 콘텐츠

  • 음란물, 폭력적이거나 혐오를 조장하는 사진
  • 타인의 사진을 동의 없이 올리는 행위
  • 스팸, 광고, 투표와 무관한 사진

신고와 차단

  • 투표 페이지의 사진 신고 버튼으로 누구나 로그인 없이 신고할 수 있습니다.
  • 서로 다른 사용자 3명이 신고하면 해당 사진은 즉시 자동으로 숨겨집니다.
  • 이 사람 더 안 보기(차단)를 선택하면 그 업로더의 사진이 내 브라우저에서 더 보이지 않습니다.

처리 절차

  • 접수된 신고는 24시간 안에 검토합니다.
  • 원칙을 위반한 콘텐츠는 제거하고, 반복 위반한 업로더는 공개 기능 사용을 차단합니다.
