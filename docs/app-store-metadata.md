오늘은 무슨 색을 입을까요? 컬러 룰렛을 돌리고, 그 색을 살린 OOTD를 남겨보세요.

## 설명

Ootique는 매일 하나의 컬러를 제안하는 작은 패션 챌린지입니다.

오늘의 컬러를 확인하고 그 색을 살린 옷을 입어보세요. 사진을 남기면 Ootique 스타일의 공유 카드가 만들어집니다.

친구와 같은 6자리 코드를 입력하면 같은 컬러로 도전할 수 있습니다. 두 장의 사진을 한 카드에 담아 친구들에게 공유해보세요.

- 하루에 하나로 고정되는 오늘의 컬러
- 혼자 또는 친구와 함께하는 OOTD 챌린지
- 카메라와 사진 보관함 지원
- 혼자용 및 친구 A/B 공유 카드
- 최근 7일의 로컬 기록
- 계정 가입 없이 사용

혼자 모드의 사진과 기록은 기기에만 저장되며 서버로 전송되지 않습니다.

친구 모드에서는 연결된 두 사람이 서로의 사진을 볼 수 있도록 사진 한 장이 비공개 저장소로 전송됩니다. 이 사진은 같은 코드로 연결된 상대만 볼 수 있고, 언제든 교체하거나 삭제할 수 있습니다. 계정, 이메일, 이름은 요구하지 않습니다.

## 개인정보 표시 (App Privacy)

**주의**: 아래는 친구 모드(Supabase 백엔드) 도입 이후의 실제 동작이다.
"아무것도 수집하지 않음"으로 제출하면 허위 표시가 되어 출시 후에도 앱 제거 사유가 된다.

App Store Connect의 앱 개인정보 보호 항목에 이렇게 답한다.

- **사용자 콘텐츠 → 사진 또는 비디오**: 수집됨
  - 목적: 앱 기능 (친구와의 사진 공유)
  - 사용자 신원에 연결됨: 아니요
  - 추적에 사용: 아니요
  - 친구 모드에서 사용자가 직접 업로드할 때만 전송된다. 혼자 모드에서는 전송하지 않는다.
- **식별자 → 사용자 ID**: 수집됨
  - 목적: 앱 기능 (연결된 두 기기를 구분하는 임의 토큰)
  - 사용자 신원에 연결됨: 아니요
  - 추적에 사용: 아니요
  - 서버에는 토큰 원문이 아니라 해시만 저장한다. 이름·이메일·전화번호와 연결되지 않는다.
- **추적**: 없음. 광고 SDK와 분석 SDK를 넣지 않았다.
- 계정 가입: 없음
- 혼자 모드 사진과 기록: 기기 내부 문서 영역에만 저장, 서버 전송 없음
- 외부 공유: 사용자가 iOS 공유 시트를 직접 실행할 때만 수행
- 삭제 경로: 앱에서 사진 교체·삭제가 가능하고, 기록 화면에서 전체 로컬 데이터를 지울 수 있다.

레이트 리밋 목적으로 요청 IP를 해시해 60초 창에서만 쓰고 원본 IP는 저장하지 않는다.
Apple 개인정보 표시에는 별도 항목으로 신고하지 않지만, 심사 질의가 오면 이 내용을 답한다.

- Apple 계정 비밀번호와 2FA 코드는 공유하지 않고, 계정 정보는 최신 상태로 유지한다.

- 이 이용약관은 사이트 사용 조건이다. 판매 수수료·정산·환불·세금은 별도 Apple Developer 계약을 확인한다.

## EU 디지털서비스법 거래자 자격

- EU에 배포하지 않더라도 App Store Connect에서 거래자 여부는 선언해야 한다.
- Ootique는 인앱결제로 수익을 낼 목적이므로 Apple의 판단 요소상 `거래자`에 해당할 가능성이 높다. 최종 선택은 본인이 한다.
- 개인 개발자가 거래자로 EU에 배포하면 주소 또는 사서함, 전화번호, 이메일이 App Store 상품 페이지에 공개된다. 이메일·전화 인증과 주소 증빙도 필요하다.
- 집 주소 공개를 원하지 않으면 확인 가능한 사서함 등 대체 주소를 준비하거나 첫 출시에서 EU 27개 지역을 제외하는 선택을 검토한다.
- Apple도 법률 자문이 아니라고 명시하므로 불확실하면 전문가에게 확인한다.

## 심사 메모 초안

로그인과 계정 가입이 필요하지 않습니다.

1. 첫 화면에서 `오늘의 컬러 뽑기`를 누릅니다.
2. `OOTD 촬영하기`에서 카메라 또는 사진 보관함을 사용합니다.
3. 친구 모드: `친구와` 탭에서 `코드 만들기`를 누르면 6자리 코드가 나옵니다.
   두 번째 기기에서 그 코드를 입력해 참가를 요청하고, 첫 기기에서 승인하면 방이 두 명으로 닫힙니다.
   코드는 10분 뒤 만료됩니다.
4. 친구 모드에서 각자 사진 한 장을 올리면 상대 화면에 자동으로 표시되고, 두 장이 모이면 A/B 공유 카드를 만들 수 있습니다.
5. 친구 모드의 사진은 비공개 저장소로 전송되며 같은 방의 상대만 조회할 수 있습니다.
   기기별 임의 토큰으로 인증하고 서버에는 그 해시만 저장합니다. 공개 URL을 만들지 않습니다.
6. 혼자 모드의 사진과 기록은 기기에만 저장됩니다.
7. 사용자는 언제든 사진을 교체·삭제할 수 있고, `기록` 화면에서 전체 로컬 데이터를 삭제할 수 있습니다.

**심사자가 친구 모드를 두 기기로 시험할 수 없는 경우**: 한 기기에서 코드를 만들고
시뮬레이터나 두 번째 기기에서 참가하면 됩니다. 계정이 없어 별도 심사용 로그인 정보는 제공하지 않습니다.

### 사용자 생성 콘텐츠(UGC) 관련

친구 모드는 서로 코드를 직접 주고받아 연결한 1:1 비공개 방입니다.
공개 피드, 검색, 낯선 사용자 노출이 없습니다. 사용자는 자기 사진을 언제든 삭제할 수 있습니다.
(공개 투표·순위는 이번 버전에 포함되지 않습니다. 추가할 때 신고·차단 기능을 함께 넣어야 합니다.)
